# cmdTunnel-datapack

cmdTunnel is a Minecraft datapack system that executes commands stored in storage using a temporary command block pipeline.

## Features

- Executes commands from storage
- Uses command blocks internally
- Supports dispatch hooks using function tags
- Lightweight and fully datapack-based
- Designed for advanced automation systems

## Requirements

- Minecraft Java Edition
- Datapack support enabled
- Operator permissions
- Command blocks enabled
